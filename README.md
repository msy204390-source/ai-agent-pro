# AI Agent Pro SaaS — النسخة النهائية القابلة للتطوير

هذه النسخة تحوّل المشروع من صفحة تجريبية إلى SaaS بسيط:
- تسجيل وإنشاء حسابات.
- جلسات دخول آمنة عبر Cookie HttpOnly.
- ملف إعدادات لكل عميل: الشركة، المجال، ونبرة الوكيل.
- وكيل AI حقيقي عبر OpenAI Responses API عندما يوضع المفتاح على الخادم.
- حدود استخدام شهرية حسب الخطة.
- خطط Starter $29 / Business $79 / Pro $149 لمدة 30 يوماً.
- إنشاء دفع ديناميكي عبر Kazawallet عند توفر Merchant API.
- Webhook للتحقق من دفع Kazawallet وتفعيل الاشتراك تلقائياً.
- رابط Starter اليدوي الموجود كخطة احتياطية.
- لا يوجد أي كود للكاميرا أو ألبوم الصور أو رفع الصور.
- بيانات المشروع المحلية تحفظ في `data/db.json`؛ هذه مناسبة للـMVP وليست بديلاً عن قاعدة بيانات مُدارة عند التوسع الكبير.

## التشغيل
1. ثبّت Node.js.
2. `npm install`
3. انسخ `.env.example` إلى `.env`.
4. ضع `OPENAI_API_KEY` على الخادم فقط.
5. ضع `ADMIN_EMAIL` و`ADMIN_PASSWORD` قويين.
6. شغّل `npm start`.

## الدفع الآلي عبر Kazawallet
من وثائق Kazawallet الحالية: إنشاء رابط الدفع API يتم عبر `/createPaymentLink`، ويمكن إرسال `ref` لربط الدفع بالمستخدم، وKazawallet يرسل Webhook عند اكتمال الدفع. التحقق من Webhook يحتاج API key + API secret بالطريقة الموصوفة في وثائقهم.

ضع:
- `KAZA_API_KEY`
- `KAZA_API_SECRET`
- `KAZA_MERCHANT_EMAIL`
- `APP_URL` بعنوان الموقع العام

ثم اضبط Webhook في حساب التاجر على:
`https://YOUR-DOMAIN.com/api/kazawallet/webhook`

**لا تضع API key أو API secret داخل HTML أو GitHub أو الرسائل.**

## مهم قبل البيع الحقيقي
- يجب أن يكون حساب Merchant والبيانات القانونية حقيقية ومطابقة لصاحب الحساب/النشاط.
- الدفع الحالي $29 اليدوي لا يثبت للموقع وحده أن شخصاً معيناً دفع؛ الربط التلقائي يحتاج Merchant API + Webhook.
- لا تستخدم بيانات أو مستندات وهمية عند التسجيل.
- إذا كان الحساب التجاري باسم والدتك، يجب أن تكون هي صاحبة الحساب فعلاً وموافقة على استخدامه.
